# Quantitative Experiments Registry

This directory archives controlled empirical experiments and backtest runs.

## Experiment Log Schema

Every experiment is recorded with:
1. **Experiment ID**: Unique timestamp-based identifier (e.g. `EXP-2026-04-15-01`).
2. **Hypothesis**: Specific economic question tested.
3. **Target Round & Instrument**: Target asset(s).
4. **Baseline Model vs. Variant**: Parameter differences.
5. **Observed Metrics**: In-sample vs out-of-sample Sharpe, PnL, Drawdown.
6. **Conclusion**: Accepted / rejected / revised.
