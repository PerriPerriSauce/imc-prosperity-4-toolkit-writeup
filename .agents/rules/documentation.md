# Documentation Rules

- Use professional technical writing.
- Explain methodology before conclusions.
- Include formulas where appropriate.
- Explain the assumptions behind every model.
- Distinguish actual, simulated and estimated results.
- Include limitations and failure modes.
- Use reproducible code examples.
- Attribute external material.
