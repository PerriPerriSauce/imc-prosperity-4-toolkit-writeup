# Research Rules

- Start with descriptive statistics and data validation.
- Explain the economic or microstructural hypothesis.
- Distinguish correlation from causation.
- Use appropriate statistical tests.
- Avoid look-ahead bias and data leakage.
- Document model assumptions.
- Compare against meaningful baselines.
- Report uncertainty and sensitivity.
- Keep exploratory findings separate from confirmed findings.
- Save reproducible analysis scripts.
